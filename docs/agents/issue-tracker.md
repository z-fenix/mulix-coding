# Issue tracker: GitHub

Use GitHub Issues in `z-fenix/mulix-coding`. Pass `--repo z-fenix/mulix-coding` to `gh` issue and label commands so a fork or local default cannot redirect them.

- Publish a spec or ticket with `gh issue create`, passing the Markdown body with `--body-file`.
- Read or find issues with `gh issue view` or `gh issue list`; filter by state and label as needed.
- Use `gh issue comment`, `gh issue edit`, and `gh issue close` for authorized updates.
- Resolve triage roles through [Triage labels](triage-labels.md).

**PRs as a request surface: no.**
