# 跟踪器维护规格与任务，Mulix 独立保留验收证据

远程协作需要团队能够共同维护规格与任务，但 Issue 的关闭状态不能证明实际验收或合入。将跟踪状态当作验收结论，会丢失本次验收所依据的内容和实际证据。

## 决定

远程模式下，Issue 正文是规格与任务的权威来源；阶段检查与验收使用经核对的本地[门禁快照](../GLOSSARY.md)，并结合 Mulix 独立保留的真实测试回执和审阅记录。无法核对远程内容时暂停向前推进。本地模式以本地 Markdown 维护规格与任务，不依赖远程跟踪器。

Issue 关闭不证明验收通过，也不证明已合入；合入与归档仍遵循 [ADR 0001](0001-separate-exploration-from-delivery.md)。

## 取舍

相比将 Issue 关闭直接视为验收，核对快照并在远程无法验证时暂停会降低离线推进的便利性，但能确认阶段检查与验收使用的输入，并保留独立证据。
